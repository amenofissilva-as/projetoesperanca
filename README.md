# projetoesperanca
Projeto Esperança Atividade Prática III
PROJETO ONG - INSTITUTO ESPERANÇA (exemplo acadêmico)

Estrutura:
- index.html: página única reunindo apresentação, projetos, cadastro e contato.
- css/style.css: estilos separados do HTML.
- js/script.js: máscaras e validações do formulário.
- imagens/logo.svg e imagens/comunidade.svg: recursos vetoriais usados no projeto.

Como abrir:
1. Extraia a pasta ONG_Projeto.
2. Abra index.html no navegador.
3. Não altere a relação entre as pastas, pois os caminhos são relativos.

Observações:
- O formulário valida no navegador, mas não envia nem armazena dados.
- Os dados institucionais são demonstrativos e devem ser substituídos antes de publicar.
- As imagens SVG são vetoriais e escaláveis. O projeto usa estes recursos diretamente, sem necessidade de cópias JPG/PNG/WebP.
- Antes da entrega, valide index.html em https://validator.w3.org/
